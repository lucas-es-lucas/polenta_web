# Polenta Web — Changelog

Este archivo registra cambios funcionales, estructurales, técnicos o de documentación que ayuden a comprender la evolución del proyecto. No pretende incluir modificaciones menores.

## Formato

Cada entrada debe indicar fecha, tipo de cambio, descripción breve y, cuando corresponda, áreas afectadas.

Tipos sugeridos: `Added`, `Changed`, `Fixed`, `Removed` y `Documentation`.

## Historial

### 2026-10-02

#### Documentation

- Se incorporó la documentación base del proyecto a `main` mediante `branch_documentation`.
- Se documentó el estado actual del bloque Hero + Tickets, la carga dinámica de Tickets y las reglas de mantenimiento de la documentación.
- La documentación se limitó al comportamiento presente en `main`.

## Regla de mantenimiento

Agregar una entrada al completar un cambio relevante. No registrar cambios triviales que no aporten información útil sobre la evolución del proyecto.
